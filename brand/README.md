# Tucano Technology brand assets

Original source assets supplied by Tucano Technology. The website uses optimised copies under
`site/assets/brand/`:

- `tucano-mark-original.png` — the pixel-art toucan on its original white background. The website
  uses `site/assets/brand/tucano.png`, an identical pixel grid with only the border-connected white
  made transparent (the white face and eye highlights inside the bird are preserved).
- `tucano-technology-logo.png` and `.ai` — the full Tucano Technology lockup (toucan + wordmark).

The toucan is pixel art. Always scale it with `image-rendering: pixelated`; do not smooth, recolour,
crop or add filters to it (Firefox renders a white box behind transformed, filtered pixel art). Use
`mix-blend-mode: multiply` only when placing the white-backed full logo on a light surface.

official project and must not be used to imply endorsement by another product.
