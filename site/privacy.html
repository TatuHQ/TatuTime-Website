Privacy

This site collects nothing.

No cookies. No analytics. No telemetry. No advertising pixels. No third-party fonts or scripts. No contact form quietly posting somewhere. The page you are reading is plain HTML, CSS and a small local JavaScript file.

What the website does

  • All assets — fonts included — are served from this domain. The page makes no external network requests.
  • No data is stored in your browser: no cookies, no localStorage, no session identifiers.
  • No usage data is sent anywhere. There is no analytics service to send it to.
  • Outbound links (GitHub, documentation) are ordinary links. Nothing is loaded from those sites unless you click one.

Server logs

This site can be served two ways:

  • GitHub Pages. GitHub is the host and may process standard request data (such as IP addresses) to deliver the site and protect its service. That processing is governed by GitHub's own privacy statement, not by Tucano Technology.
  • Self-hosted container. The Caddy configuration in this repository does not enable access logging. If an operator adds a log or puts the site behind a proxy, that operator decides what is recorded.

This page is static, so there is no account, no comment box and no newsletter to unsubscribe from.

The Tucano Time product

Tucano Time is different from this website: it is software you run yourself. It has no cloud account, no telemetry and no AI features. Your timesheets, clients and invoices stay in your data directory. Network calls happen only for integrations the operator explicitly configures — mail, calendar, OIDC single sign-on, or optional accounting sync — plus the European Central Bank's anonymous daily exchange-rate feed used for currency conversion, which can be replaced with a local file. Credentials live in an encrypted local vault.

The detailed security model is in the product documentation.

Questions

Ask in the open on the Tucano Time issue tracker. There is no privacy inbox because there is no data to request, export or delete from this site.
